# 房价热力图功能使用说明

## 功能简介

本项目已成功将高德地图热力图功能集成到 ToolsPage（实用工具页面）中，可以直观地展示不同区域的房价分布情况。热力图使用颜色深浅来表示房价高低，让用户能够快速了解各区域的房价情况。

## 使用步骤

### 步骤 1: 更新数据库

在数据库中执行更新脚本：

```bash
# 连接到 MySQL 数据库
mysql -u root -p bigdata

# 执行更新脚本
source D:/pybd/bigdatasoftware2/Targeting_specialized_fields_1/backend/热力图数据库更新.sql
```

### 步骤 2: 申请高德地图 API Key

1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 注册并登录账号
3. 进入"控制台" → "应用管理" → "我的应用"
4. 创建新应用，选择"Web 端(JS API)"
5. 获取 Key

### 步骤 3: 配置高德地图 Key

打开 `frontend/src/views/ToolsPage.vue` 文件，搜索 `YOUR_AMAP_KEY`：

```typescript
window.AMap = await AMapLoader.load({
  key: "YOUR_AMAP_KEY", // ⚠️ 替换为你的高德地图 Key
  version: "2.0",
  plugins: ["AMap.HeatMap"],
});
```

将 `'YOUR_AMAP_KEY'` 替换为你申请的实际 Key。

### 步骤 4: 启动后端服务

```bash
cd backend
mvn clean package
mvn spring-boot:run
```

或者在 IDE 中运行 `SpringbootVueDemoApplication.java`

### 步骤 5: 启动前端服务

```bash
cd frontend
npm install # 首次运行需要安装依赖
npm run dev
```

### 步骤 6: 访问热力图功能

在浏览器中访问：

1. 登录页面: http://localhost:5173/login
2. 实用工具页面: http://localhost:5173/tools
3. 点击顶部的 "🗺️ 价格热力图" 标签查看热力图

## 功能特性

### 1. 城市切换

- 支持北京、上海、广州、深圳等主要城市
- 切换城市时自动定位到对应城市中心

### 2. 价格筛选

- 全部价格
- 0-5 万/㎡
- 5-10 万/㎡
- 10-15 万/㎡
- 15 万/㎡ 以上

### 3. 热力图控制

- 透明度调节（0-100%）
- 刷新数据按钮
- 实时更新热力图显示

### 4. 视觉效果

- 绿色：低价区域
- 黄色：中等价位区域
- 红色：高价区域
- 颜色越深，表示该区域房源越集中

## API 接口说明

### 获取热力图数据

**请求:**

```
GET /api/heatmap/data?city=beijing&priceRange=all
```

**参数:**

- `city`: 城市代码（可选）
- `priceRange`: 价格范围（可选）

**响应:**

```json
{
  "success": true,
  "data": [
    {
      "longitude": 114.123456,
      "latitude": 22.54321,
      "price": 85000,
      "propertyName": "万科城市花园",
      "district": "南山区"
    }
  ],
  "total": 1000
}
```

### 获取统计信息

**请求:**

```
GET /api/heatmap/stats?city=beijing
```

**响应:**

```json
{
  "success": true,
  "data": {
    "totalCount": 1000,
    "avgPrice": 85000,
    "minPrice": 50000,
    "maxPrice": 150000
  }
}
```

## 注意事项

1. **高德地图 Key**: 必须申请并配置有效的高德地图 Key，否则地图无法显示
2. **数据库经纬度**: 确保数据库中的房源有经纬度信息
3. **跨域设置**: 后端已配置 CORS 允许前端访问
4. **数据量**: 热力图接口限制返回 2000 条数据，避免性能问题

## 故障排查

### 地图不显示

- 检查高德地图 Key 是否正确
- 检查浏览器控制台是否有错误信息
- 确认网络连接正常

### 热力图无数据

- 执行数据库更新脚本
- 检查数据库中是否有经纬度信息
- 查看后端日志确认 API 是否正常

### 接口报错

- 检查后端服务是否启动
- 确认数据库连接正常
- 查看后端控制台错误信息
