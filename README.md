## 🚀 快速开始

### 环境要求

- **Java**: JDK 8+
- **Node.js**: v16+
- **MySQL**: 5.7+
- **Maven**: 3.6+

### 启动步骤

1. **克隆项目**

   ```bash
   git clone <repository-url>
   cd Targeting_specialized_fields_1
   ```

2. **启动后端服务**

   ```bash
   cd backend
   mvn spring-boot:run
   ```

3. **启动前端服务**

   ```bash
   cd frontend
   npm install
   npm run dev
   ```

4. **访问应用**
   - 前端: http://localhost:5173
   - 后端 API: http://localhost:8080

### 数据库配置

1. 创建数据库: `bigdata`
2. 执行数据库更新脚本
3. 配置热力图数据（可选）
