# 房价信息注入脚本使用说明

## 功能说明

该脚本用于将CSV格式的房价数据导入到MySQL数据库中。脚本会自动处理以下数据：

1. **小区信息** (`communities` 表)
   - 自动去重（同一城市同名小区）
   - 提取小区基本信息、位置信息、设施信息

2. **房源信息** (`properties` 表)
   - 根据CSV数据创建房源记录
   - 包含基本信息、价格信息、户型信息

3. **成交记录** (`transaction_records` 表)
   - 记录每笔成交的详细信息

## 环境要求

- Python 3.7+
- MySQL 8.0+
- 已安装必要的Python包

## 安装依赖

```bash
cd backend/src/main/数据库脚本
pip install -r requirements.txt
```

或者手动安装：

```bash
pip install pandas pymysql
```

## 配置数据库连接

编辑 `注入房价信息.py` 文件，修改 `DB_CONFIG` 字典中的数据库连接信息：

```python
DB_CONFIG = {
    'host': 'localhost',        # 数据库主机
    'port': 3306,               # 端口
    'user': 'bigdata_user',     # 用户名
    'password': '123456',        # 密码
    'database': 'bigdata',       # 数据库名
    'charset': 'utf8mb4'
}
```

## 使用方法

1. 确保CSV文件放在脚本同级目录下：
   - `上海合并数据_清洗.csv`
   - `北京合并数据_清洗.csv`
   - `天津合并数据_清洗.csv`

2. 运行脚本：

```bash
python 注入房价信息.py
```

## CSV文件格式要求

CSV文件应包含以下列（列名必须匹配）：

- `name` - 小区名称
- `城市` - 城市名称
- `area` - 区域名称
- `address` - 详细地址
- `经度` - 经度坐标
- `纬度` - 纬度坐标
- `建筑年份_数值` - 建筑年份
- `小区面积_数值` - 小区总面积
- `小区户数_数值` - 小区总户数
- `容积率_数值` - 容积率
- `绿化率_数值` - 绿化率
- `物业费_数值` - 物业费
- `面积（m²）` - 房源面积
- `室数` - 卧室数量
- `厅数` - 客厅数量
- `卫数` - 卫生间数量
- `总楼层数` - 总楼层数
- `当前楼层估算` - 当前楼层
- `朝向评分` - 朝向评分（1-5）
- `成交单价（元）` - 成交单价
- `成交金额（万元）` - 成交总价（万元）
- `成交年份` - 成交年份
- `成交月份` - 成交月份

## 注意事项

1. **数据去重**：脚本会自动处理同名小区的去重问题
2. **批量提交**：每100条记录提交一次，提高性能
3. **错误处理**：如果某行数据出错，会跳过并继续处理下一行
4. **编码问题**：脚本会自动尝试多种编码（utf-8, gbk, gb18030）

## 故障排除

1. **连接失败**：检查数据库是否运行，用户名密码是否正确
2. **编码错误**：确保CSV文件编码正确，脚本会自动尝试多种编码
3. **字段缺失**：检查CSV文件是否包含所有必需的列
4. **内存不足**：如果数据量很大，可以考虑分批处理
