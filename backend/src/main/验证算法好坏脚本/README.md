# 相似性算法验证脚本

## 功能说明

本脚本用于验证房源相似性和用户相似性计算结果的优劣好坏，通过多种指标和可视化分析来评估算法的有效性。

## 验证内容

### 房源相似性验证

1. **基本统计信息**
   - 平均相似度、中位数、标准差
   - 相似度分布情况
   - 高相似度比例

2. **同一小区验证**
   - 验证同一小区的房源是否比不同小区的房源更相似
   - 这是最基础的验证，应该通过

3. **价格相似性验证**
   - 验证价格相近的房源是否更相似
   - 计算价格差异与相似度的相关性

4. **户型相似性验证**
   - 验证相同户型的房源是否更相似
   - 比较相同卧室数和不同卧室数的房源相似度

5. **可视化分析**
   - 相似度分布直方图
   - 同一小区 vs 不同小区的对比箱线图
   - 不同算法的相似度分布对比

### 用户相似性验证

1. **基本统计信息**
   - 平均相似度、中位数、标准差
   - 相似度分布情况

2. **行为相似性验证**
   - 验证有共同浏览行为的用户是否更相似
   - 比较有共同行为和没有共同行为的用户相似度

3. **偏好相似性验证**
   - 验证偏好相似的用户是否更相似
   - 计算位置偏好、价格范围偏好的重叠度与相似度的相关性

4. **聚类结果验证**
   - 检查用户聚类结果
   - 验证同一聚类内的用户是否更相似

5. **可视化分析**
   - 相似度分布直方图
   - 有共同行为 vs 无共同行为的对比
   - 不同算法的相似度分布对比

## 验证标准

### 房源相似性验证标准

1. **同一小区验证**
   - 同一小区的平均相似度应该比不同小区高至少 0.1
   - 如果差异 < 0.1，说明算法可能存在问题

2. **价格相似性验证**
   - 价格差异与相似度应该呈负相关（相关系数 < -0.2）
   - 价格越接近，相似度应该越高

3. **户型相似性验证**
   - 相同户型的平均相似度应该比不同户型高至少 0.05
   - 如果差异很小，说明户型特征权重可能不够

### 用户相似性验证标准

1. **行为相似性验证**
   - 有共同行为的用户平均相似度应该比没有共同行为的高至少 0.1
   - 如果差异 < 0.1，说明行为特征权重可能不够

2. **偏好相似性验证**
   - 偏好重叠度与相似度应该呈正相关（相关系数 > 0.3）
   - 偏好越相似，用户相似度应该越高

3. **聚类结果验证**
   - 同一聚类内的平均相似度应该比不同聚类间高至少 0.1
   - 如果差异很小，说明聚类效果不明显

## 常见问题

### 1. 未找到相似度数据

**问题**: 脚本提示"未找到相似度数据"

**解决方案**: 
- 确保已经运行过相似度计算算法
- 检查数据库连接配置是否正确
- 检查 `property_similarity` 和 `user_similarity` 表中是否有数据

### 2. 验证结果不理想

**问题**: 某些验证项显示警告或失败

**可能原因**:
- 数据量不足
- 算法参数需要调整
- 特征权重配置不合理

**解决方案**:
- 增加测试数据量
- 调整算法参数（如相似度阈值、特征权重等）
- 检查特征提取是否正确

### 3. 图表无法显示中文

**问题**: 图表中的中文显示为方框

**解决方案**:
- 确保系统已安装中文字体（SimHei、Microsoft YaHei等）
- 或者修改脚本中的字体配置

## 扩展功能

可以根据需要添加以下验证功能：

1. **推荐效果验证**
   - 验证推荐给用户的房源是否符合用户偏好
   - 计算推荐准确率、召回率等指标

2. **实时性验证**
   - 验证相似度计算的实时性
   - 检查增量更新是否正常工作

3. **性能验证**
   - 验证算法计算时间
   - 检查大数据量下的性能表现

4. **稳定性验证**
   - 多次运行算法，检查结果是否稳定
   - 验证随机性对结果的影响

## 注意事项

1. **数据准备**: 确保数据库中有足够的测试数据
2. **计算资源**: 大规模数据验证可能需要较长时间
3. **结果解读**: 验证结果仅供参考，需要结合业务场景判断
4. **定期验证**: 建议在算法更新后定期运行验证脚本
