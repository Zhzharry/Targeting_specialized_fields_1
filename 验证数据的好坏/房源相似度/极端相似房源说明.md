# 极端相似房源说明

## 数据生成方式

房源数据生成脚本 `generate_extreme_property_data.py` 使用的是**固定配置模板**，不是完全随机生成的。

## 极端相似的房源

### 相似房源ID范围
- **起始ID**: `10000`
- **结束ID**: `19999`
- **数量**: 每个相似小区生成5个房源，共3个相似小区，总计约15个房源

### 极端相似的两个房源示例

**房源ID: 10000 和 10001** 是极端相似的，它们具有：

#### 相同的配置模板：
- **价格范围**: 400-600万（相同范围，略有浮动）
- **面积范围**: 90-120平米（相同范围，略有浮动）
- **户型**: 3室2厅2卫（完全相同）
- **朝向**: 南向（south，完全相同）
- **装修**: 精装（完全相同）
- **建造年份**: 2018年（完全相同）
- **楼层**: 15-19层（略有不同，但都在同一范围）
- **总楼层**: 28层（完全相同）

#### 相同的小区特征：
- **位置**: 南山区（完全相同）
- **坐标**: 非常接近（经纬度差异在0.01度以内）
- **物业费**: 3.5元/㎡（完全相同）
- **绿化率**: 35%（完全相同）
- **容积率**: 2.5（完全相同）

### 预期相似度

这些极端相似的房源预期相似度应该：
- **相似度分数**: > 0.7（70%以上）
- **聚类结果**: 应该被分到同一个簇（cluster）
- **相似度类型**: 所有相似度指标（余弦、欧几里得、加权）都应该较高

## 极端不相似的房源

## 验证方法

### 1. 查询极端相似房源
```sql
-- 查看房源10000和10001的详细信息
SELECT 
    property_id,
    title,
    JSON_EXTRACT(price_info, '$.total_price') as total_price,
    JSON_EXTRACT(layout_info, '$.area') as area,
    JSON_EXTRACT(layout_info, '$.bedroom_count') as bedroom,
    JSON_EXTRACT(layout_info, '$.orientation') as orientation,
    JSON_EXTRACT(basic_info, '$.decoration') as decoration
FROM properties
WHERE property_id IN (10000, 10001);
```

### 2. 查询它们的相似度
```sql
-- 查看房源10000和10001的相似度
SELECT 
    property_id1,
    property_id2,
    JSON_EXTRACT(similarity_data, '$.similarity_score') as similarity_score,
    JSON_EXTRACT(similarity_data, '$.cosine_similarity') as cosine_sim,
    JSON_EXTRACT(similarity_data, '$.weighted_similarity') as weighted_sim,
    JSON_EXTRACT(similarity_data, '$.same_cluster') as same_cluster,
    JSON_EXTRACT(similarity_data, '$.cluster_id') as cluster_id
FROM property_similarity
WHERE (property_id1 = 10000 AND property_id2 = 10001)
   OR (property_id1 = 10001 AND property_id2 = 10000);
```

### 3. 查看所有相似房源对
```sql
-- 查看所有极端相似房源（ID 10000-19999）的相似度
SELECT 
    property_id1,
    property_id2,
    JSON_EXTRACT(similarity_data, '$.similarity_score') as similarity_score,
    JSON_EXTRACT(similarity_data, '$.cluster_id') as cluster_id
FROM property_similarity
WHERE property_id1 >= 10000 AND property_id1 < 20000
  AND property_id2 >= 10000 AND property_id2 < 20000
ORDER BY JSON_EXTRACT(similarity_data, '$.similarity_score') DESC
LIMIT 20;
```
