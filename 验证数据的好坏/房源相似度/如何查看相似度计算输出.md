# 如何查看房源相似度计算输出

## 1. 调用接口

房源相似度计算通过以下接口触发：

### 接口信息
- **URL**: `POST http://localhost:8080/api/similarity/calculate`
- **说明**: 异步执行完整计算（基于内容 + 协同过滤 + 结果融合）

### 调用方式

#### 方式1：使用 Postman 或类似工具
```
POST http://localhost:8080/api/similarity/calculate
Content-Type: application/json
```

#### 方式2：使用 curl 命令
```bash
curl -X POST http://localhost:8080/api/similarity/calculate
```

#### 方式3：使用浏览器控制台（前端）
```javascript
fetch('http://localhost:8080/api/similarity/calculate', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  }
})
.then(response => response.json())
.then(data => console.log(data));
```

## 2. 查看输出位置

### 后端控制台输出（主要输出位置）

由于接口是**异步执行**的，所有详细的日志和评估指标都会输出到**后端控制台**（运行Spring Boot的终端窗口）。

#### 输出内容包括：

1. **聚类评估指标**（新增）
   ```
   ========== 聚类评估指标 ==========
   WSSSE (Within Set Sum of Squared Errors): 1234.5678
   Silhouette Score (轮廓系数): 0.6543 (范围: -1到1，越接近1越好)
   Davies-Bouldin Index (DB指数): 0.4321 (越小越好)
   Average Intra-Cluster Distance (平均类内距离): 12.3456
   Average Inter-Cluster Distance (平均类间距离): 45.6789
   Separation Ratio (分离度): 3.7012 (类间距离/类内距离，越大越好)
   =====================================
   ```

2. **聚类结果**
   ```
   K-Means聚类完成，聚类数量: 8，处理了 100 条数据（使用Spark RDD）
       簇0: 12个房源
       簇1: 15个房源
       ...
   ```

3. **相似度计算进度**
   ```
   [Spark RDD计算] 开始使用Spark RDD计算同簇内房源相似度...
     计算簇0的相似度，包含 12 个房源
     计算簇1的相似度，包含 15 个房源
   ...
   [Spark RDD计算] 相似度计算完成，共保存了 234 对同簇房源相似度数据
   ```

### 接口返回（立即返回）

接口会立即返回一个JSON响应，表示任务已启动：

```json
{
  "success": true,
  "message": "相似度计算任务已启动，请稍后查看结果",
  "timestamp": 1234567890
}
```

**注意**：这个响应只表示任务已启动，不包含计算结果。实际的计算过程和结果都在后端控制台输出。

## 3. 其他相关接口

### 只计算基于内容的相似度（同步，可查看耗时）
```
POST http://localhost:8080/api/similarity/calculate/content
```
这个接口是同步执行的，会等待计算完成并返回耗时。

### 查看相似度统计信息
```
GET http://localhost:8080/api/similarity/stats
```

返回示例：
```json
{
  "success": true,
  "total_similarity_pairs": 234,
  "average_similarity_score": 0.7234,
  "same_cluster_pairs": 234,
  "cf_similarity_pairs": 0
}
```

### 查看指定房源的相似房源
```
GET http://localhost:8080/api/similarity/properties/{propertyId}?limit=10
```

## 4. 查看数据库结果

计算完成后，相似度数据会保存到 `property_similarity` 表：

```sql
SELECT 
    property_id1,
    property_id2,
    JSON_EXTRACT(similarity_data, '$.similarity_score') as similarity_score,
    JSON_EXTRACT(similarity_data, '$.cluster_id') as cluster_id,
    JSON_EXTRACT(similarity_data, '$.same_cluster') as same_cluster
FROM property_similarity
ORDER BY JSON_EXTRACT(similarity_data, '$.similarity_score') DESC
LIMIT 20;
```

## 5. 注意事项

1. **后端服务必须运行**：确保Spring Boot后端服务正在运行（`mvn spring-boot:run`）
2. **查看控制台**：所有详细输出都在运行后端的终端窗口中
3. **异步执行**：`/api/similarity/calculate` 接口是异步的，不会等待计算完成
4. **计算时间**：根据数据量，计算可能需要几分钟时间
